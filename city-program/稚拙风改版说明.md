# 城知 · 稚拙城市手册

2026-11-02。31个独立城市项目、网页总目录与原生微信小程序统一采用手册视觉。

沿用本地“知用”项目的配色语言：奶油纸 `#f5f0df`、蓝墨 `#3555ac`、砖红 `#b94e32`、便签黄 `#f5df91`、鼠尾草绿 `#e4e9cb`。边框轻微不规则、纸片硬阴影、系统楷体标题、胶带照片卡和印章用于建立辨识度；正文、出处、表单和地图保持平直。真实照片及其署名、拍摄日期和许可保留；没有用生成图片代替实景，也没有复制其他项目的插画或商标。

第二版按“手绘城市手册”方向升级：减少重复边框，纸纤维背景、胶带照片、手写旁注、章节编号与档案夹专题共同建立纸页层次。六个生活入口使用原创SVG小画，表达住房、工作、读书、健康、交通和办事；这些是装饰画，不是当地建筑或设施的事实图片。首页专题不再重复使用同一张城市照片，真实照片仍在首页及图片来源中保留。

网页样式按 `src/styles.css → src/city-content.css → src/naive.css → src/handbook.css` 加载。装饰组件为各城自己的 `src/handbook-art.jsx`。原生微信样式按 `miniprogram/base.wxss → miniprogram/naive.wxss → miniprogram/handbook.wxss` 加载，标题和正文层级、生活便签、档案夹与导航配色同步调整；原生标题仍使用系统楷体，尚未进行微信编译或真机验证。总目录新增 `city-program/handbook.css`。

网页标题使用[站酷快乐体](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile)，依据同目录OFL许可制作约71KB的字形子集；每城在 `public/fonts/title.woff2` 独立保存，许可为 `public/fonts/OFL.txt`。运行时只从本项目加载，不请求在线字体；缺字回退到系统字体。原始字体和字形子集工具缓存不随源码提交，总目录另有独立的字体副本与 `FONT_LICENSE.txt`。字体只用于标题和装饰，正文保持系统无衬线字体。

修改北京的主题后，可执行 `python city-program/sync-styles.py` 同步样式，再分别构建城市。同步是开发辅助；各城市运行、打包时仍使用自己的文件。

本次改版没有增加资料研究数量，也没有改变既有资料覆盖边界。网页预览与原生结构检查不能代替微信开发者工具编译或真机验证。
