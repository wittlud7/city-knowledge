# 城知 · 稚拙城市手册

2026-11-02。31个独立城市项目、网页总目录与原生微信小程序统一采用手册视觉。

沿用本地“知用”项目的配色语言：奶油纸 `#f5f0df`、蓝墨 `#3555ac`、砖红 `#b94e32`、便签黄 `#f5df91`、鼠尾草绿 `#e4e9cb`。边框轻微不规则、纸片硬阴影、系统楷体标题、胶带照片卡和印章用于建立辨识度；正文、出处、表单和地图保持平直。真实照片及其署名、拍摄日期和许可保留；没有用生成图片代替实景，也没有复制其他项目的插画或商标。

网页样式为各城的 `src/naive.css`，在原有布局样式后加载。原生微信样式按 `miniprogram/base.wxss → miniprogram/naive.wxss` 顺序加载，导航与标签栏色彩同步；未依赖外部字体。总目录使用 `city-program/naive.css`。

修改北京的主题后，可执行 `python city-program/sync-styles.py` 同步样式，再分别构建城市。同步是开发辅助；各城市运行、打包时仍使用自己的文件。

本次改版没有增加资料研究数量，也没有改变既有资料覆盖边界。网页预览与原生结构检查不能代替微信开发者工具编译或真机验证。
