# 公共地图参考点的范围

本次对30个新增城市的90个固定命名公共文化机构做了一次离线位置查询。按 [Nominatim 使用政策](https://operations.osmfoundation.org/policies/nominatim/) 单线程、单机器、请求间隔至少1.1秒，并保存结果；只对未匹配的名称做一次带城市范围的澄清。没有下载某个区域的全部地点，没有将公共接口接入程序的实时搜索或自动补全。

最终采用70条公共地图参考记录。排除了跨省结果、名称不符、地铁站、公交站和只有“图书馆”等泛称的结果。部分原数据以园区范围标记机构，作为参考点保留，并未当作精确入口。另有原先已通过机构资料确认的地点仍无坐标，界面不会替其编造位置。

太原、沈阳、杭州、贵阳和南昌的多馆区问题另读了公开资料核对。来源与具体采用的馆区见 `campus-reviews.json`；南昌资料中的第三方预约描述存在不一致，仅采用馆址线索，不将其作为当前预约规则。

每个城市的 `content/public-map.json` 保留参考位置、原始OSM记录链接、读取日期、许可与未匹配名称。资料版权标注为 **© OpenStreetMap contributors，ODbL 1.0**，许可见 [Open Data Commons](https://opendatacommons.org/licenses/odbl/1-0/)，[OSM版权说明](https://www.openstreetmap.org/copyright)。这些地图索引按其相应许可提供；其他政府摘要与照片分别保留自己的来源或许可。

地图记录的存在不表示机构正在开放，也不代表某个出入口、无障碍设施、预约办法或收费标准已经核验。规划结果是候选安排，仍须查机构当期公告；公开地图也可能滞后。本次保留的历史影像同样不作为实时状态。
