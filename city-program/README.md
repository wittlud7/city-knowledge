# 城知 · 中国大陆31城独立项目

本地总目录：[http://127.0.0.1:8790/](http://127.0.0.1:8790/)。双击本文件夹 `Start-Cities.cmd`，或执行 `node server.mjs`，按城市点击“启动并打开”。首次使用源码包请先在相应城市目录安装依赖并构建。

包括4个直辖市、22个大陆省会和5个自治区首府。北京位于 `../beijing-city-guide`；其余30个城市各自拥有一个同级 `城市英文-city-guide` 文件夹。每个文件夹含原生微信小程序、网页、Node.js服务、独立SQLite数据库、资料、照片、配置、测试和源码压缩包。各城独立运行，不通过其他城市文件夹加载数据或依赖。

目前读取并整理本地正文50篇，全国通用资料6篇（研究数量按URL去重），实景照片35张。另整理70条公共地图参考记录，总计97个地点；从14个城市的公报中补入49项保留年份和口径的生活背景事实。北京21篇正文、6个跨资料专题；其他城市各有1至2篇本地正文、6篇全国资料和3个融合专题。全国资料在每个项目中独立保存，不能把31份副本当作31次独立研究。4份已找到但未成功读取的原统计页面保留“待补读”标记；这些城市另有已读的交通或公共文化资料。

这批是可运行首版，尚非31城完整知识库或已上线政府采购产品。除北京外，本地材料仍较少；未覆盖的年度入学、社区医疗、租赁流程、地方历史、区县档案、交通细则与设施入口需要逐城补充。行程功能不会在缺少地点时自动编造线路。每城具体状态见 `content/coverage.json`，汇总见[城市项目与覆盖清单](城市项目与覆盖清单.md)。

缺少有效微信AppID和模型服务配置，默认使用检索摘要问答。代码保留模型接入能力，尚未实际调用模型或完成微信真机发布。图片均附作者、拍摄日期、原始说明页与许可，页面裁切不改变下载的图片文件。地图、天气不作为实时官方服务承诺。

验证记录见 `build-results.json` 和 `http-results.json`，详细构建日志在本地 `logs/`。结构检查不是微信编译和真机测试。批量核验：`python build-all.py --verify`；接口核验：`node verify-http.mjs`；刷新目录：`node catalog.mjs`；生成独立源码包：`python package-all.py`。不要把 `data/`、`.env` 或本地管理员密码加入交付包。

2026-11-02已统一改为“稚拙城市手册”视觉：奶油纸底、蓝墨、砖红印章、彩色便签与实景照片卡。网页主题为各城 `src/naive.css`；微信主题为 `miniprogram/naive.wxss`，原基础样式移至 `miniprogram/base.wxss`。修改北京的样式后可执行 `python sync-styles.py`，再逐城构建；详见[稚拙风改版说明](稚拙风改版说明.md)。

完整交付包为 `output/city-program-31-delivery.zip`。解压后直接得到31个独立城市文件夹和一个 `city-program` 总目录文件夹；每城 `output` 中另有单独源码包。新机器安装 Node.js 24 后，可双击 `city-program/Setup-Cities.cmd`，或在解压根目录执行 `node city-program/setup.mjs`。只准备一城可用 `node city-program/setup.mjs --city shanghai`；这些命令为各城分别安装依赖并构建，随后通过总目录启动所选城市。交付包不含个人数据库、管理员密码或密钥。

公共地图不是机构官方服务核验。匹配规则、多馆区复核与ODbL许可见[公共地图数据说明](公共地图数据说明.md)。
