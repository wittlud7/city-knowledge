# 天津 · 小程序首页样板

2026-11-02。针对手机交互重新组织首页，取代天津原生页面中大照片、装饰字体与纸片排版。网页端仍使用原有城市手册界面。本轮交付范围是天津小程序首页及其现有页面之间的连接。

## 设计依据

- [多抓鱼开发者发布的App Store截图](https://apps.apple.com/cn/app/%E5%A4%9A%E6%8A%93%E9%B1%BC/id1442757335)：参考其清爽的文字、轻量边界和内容组织。官网在本次浏览中未加载内容，未据此推断界面。
- [多邻国官方核心标签页设计文章](https://blog.duolingo.com/core-tabs-redesign/)：参考按钮反馈、明确层级与可亲近的操作。没有使用其吉祥物、商标、专属字体、积分或连胜机制。
- 手机设计目标为390×844，仅表示应用内容，不绘制系统状态栏、设备边框或微信原生胶囊。

## 字体与文字

正文和标题使用同一套无衬线字体，以字重和字号区分。微信端采用系统字体；浏览器预览独立保存OFL Noto Sans SC字形子集，避免桌面系统缺少中文字体时混用字形。字体文件和许可在 `preview/fonts/`，不增加微信主包字体资源。

首页用“找房安家、工作求职、孩子上学、就医医保、交通出行、日常办事”组织资料。专题入口改为生活问题，详情仍保留正式标题、适用范围和全部来源。真实城市照片放在次要区块，保留日期、作者及许可。

## 原生源码与预览

首页：`miniprogram/pages/home/home.wxml`、`home.js`；样式：`miniprogram/pocket.wxss`。`app.wxss`加载 `base.wxss → pocket.wxss`。图标为已使用的Lucide图标库，包含ISC许可，提供PNG以供原生image组件使用。

运行 `npm start` 后打开 <http://127.0.0.1:8801/mini/>。预览适配器读取上述原生文件和现有页面控制器，并连接同一后端；页面没有被替换成图片。它覆盖本次主要交互，不实现完整微信运行环境：原生地图、系统权限、微信身份和真实设备兼容需另行验证。

已核对：问题从首页带入问答页、真实检索返回四条引用、居住分类筛选、全部资料重置筛选、专题详情四条来源、320与390宽度无横向溢出。接口与文件访问测试共8项、小程序11页结构检查通过。设计核对见项目根目录 `design-qa.md`。

微信开发者工具仍导入本项目 `project.config.json`，实际运行与发布需自有AppID和后端配置。本次未进行微信编译或真机验证。
