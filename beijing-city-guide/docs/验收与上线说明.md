# 本地样板验收与上线边界

交付包括微信原生端、响应式网页、共用后端、内容后台、初始资料、测试和100题人工验收题库。产品名为“京知”。

## 覆盖与验证

| 领域 | 交付内容 | 已做验证 |
|---|---|---|
| 认识城市 | 16类目录、16区基础资料、区域比较、主题入口 | HTTP接口与网页交互 |
| 浏览 | 搜索、分类、区域筛选、详情、来源、收藏 | 搜索到收藏完整浏览器流程 |
| 地图 | 原生GCJ-02点位、网页OSM底图、外部地图入口 | 坐标转换测试；微信地图需真机验证 |
| 问答 | 多轮检索引用、缺口提示、历史、评价、可选模型 | 引用与缺口测试、浏览器提问；外部模型未实调 |
| 行程 | 天数、区域、兴趣、出发参考点、节奏、雨天、预算保存 | 约束测试与网页生成保存 |
| 生活 | 模板清单、自定义、完成、删除 | 浏览器修改与刷新保留 |
| 活动 | 人工核验、日期筛选、过期退出、官方入口 | 隔离数据库发布与过期测试 |
| 个人 | 游客隔离、收藏、偏好、导出、删除 | 权限与接口持久化测试 |
| 整理 | 页面短元数据采集、正文AI/规则草稿、批量JSON导入 | 规则草稿、原文隔离、导入校验测试 |
| 管理 | 新增、修改、审核、发布、归档、导出、审计 | 隔离浏览器后台操作与接口测试 |
| 运营 | 反馈处理、来源变化检查、覆盖与缺口、真实使用量 | 权限、来源请求限制、反馈状态与审计测试 |

初始内容：21个来源登记、36篇资料、24个精选地点、3套生活清单。活动默认为空，不把未核实的活动标成当前可参加。地点坐标近似，开放、票价与无障碍信息多数尚需逐项核验。区域比较只提供地理和探索主题，不提供住房、教育或安全排名。

## 当前验收结果

- 核心与HTTP接口自动测试22项。
- 10个微信页面结构、脚本语法、事件绑定检查。
- 网页生产构建；桌面1440宽和手机390宽浏览器检查。
- npm依赖审计未发现已知漏洞（检查时点结果）。
- 测试使用独立SQLite数据库，后台测试内容不会进入正式本地资料库。

截图位于 `output/playwright/`。源码包不含本地数据库、密码、会话、环境密钥、测试数据库或node_modules。

## 尚不能宣称的结果

- 没有有效AppID，未完成微信正式发布、真机兼容与平台审核。
- 环境未安装微信开发者工具，结构检查不能代替WXML/WXSS编译和真机测试。
- 未提供大模型账号，默认是资料检索与规则草稿，生成式回答和AI整理接口已编写但未调用实际付费模型验证。
- 没有全量收集北京公开资料，也没有验证产品已经优于攻略平台或通用AI。
- 没有官方采购承诺、正式授权合作或上线部署。
- 自动来源检查依赖目标站点的抓取规则、网络与页面结构；不保证所有登记站点都能自动读取。失败会提示人工核验。
- Dockerfile提供部署构建方案，当前没有实测Docker镜像。

## 进入真实试点的必要工作

1. 由账号持有者创建小程序AppID，配置实际HTTPS服务域名；密钥仅填写服务端环境。
2. 在微信开发者工具与真机检查地图、网络、文件导出、交互及隐私相关流程。
3. 核对资料使用条件，优先扩充目标街区、场馆与生活服务；按题库进行人工事实与可执行性验收。
4. 接入选定大模型，实测引用支持度、资料外问题、恶意输入、超时与费用。
5. 部署持续运行的服务、备份数据库、配置独立密码和访问控制；根据最终项目落实上线要求。
6. 用真实用户对比任务完成时间、事实错误、额外搜索次数和官方入口使用，再向潜在合作方展示证据。
