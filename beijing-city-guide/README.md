# 京知 · 北京城市指南

北京城市知识与生活助手：微信原生小程序、响应式网页、内容管理后台共用 Node.js + SQLite 服务。当前为可运行的本地样板，独立建设，未获得官方合作或背书。

## 立即体验

需要 Node.js 22.13+，推荐当前环境的 Node.js 24。

```powershell
cd "D:\03_Development\Work\公开资料知识库\beijing-city-guide"
npm ci
npm run build
npm start
```

浏览器访问 **http://127.0.0.1:8787**。开发时使用 `npm run dev`，网页地址为 http://127.0.0.1:5173 ，接口为 8787。

内容管理入口位于网页左下角。服务首次启动会生成本地管理员密码，保存在 `data/admin-password.txt`。请自行查看此文件登录；密码不会写入前端、README 或压缩包。请勿公开本地密码。数据库位于 `data/beijing.sqlite`，重启服务保留数据。

## 微信小程序

1. 安装微信开发者工具，导入**本目录**，读取根目录 `project.config.json`。
2. 使用游客模式（`touristappid`），或填入自己的 AppID。无需执行小程序 npm 构建。
3. 保持后端运行。开发者工具使用 `miniprogram/config.js` 中的 `http://127.0.0.1:8787/api`。
4. 仅本地开发配置关闭域名检查。真机需要将地址改为电脑局域网地址并配置 `HOST=0.0.0.0`；仅在可信网络中操作。
5. 正式发布需要有效 AppID、已注册的 HTTPS request 域名及相应平台配置，打开正式域名校验。不可把 localhost 配置用于正式发布。

未安装微信开发者工具的环境只能验证页面结构、脚本及业务接口，不能宣称通过微信编译或真机审核。地图、文件分享和微信身份交换还需在工具/真机验证。

## 首批数据的真实范围

- 42 个来源登记、63 篇已发布资料（21 篇正文摘要，其中本地15篇、全国6篇；6个跨资料专题；其余为导航与区域介绍）、24 个精选地点、3套可修改生活清单。
- 5 张真实拍摄照片，附作者、拍摄时间、原始说明页及开放许可。正文证据见 server/knowledge.mjs 和 content/national.json；历史资料与当年招生条件单独标明范围。
- 城市总目录位于 ../city-program，其他城市均有独立项目、端口、数据库与小程序配置。
- 分类目录覆盖16区，不表示每区已全面收录。来源目录中只有明确标记的入口做过查阅；其余为待逐项核验来源。
- 地点坐标是近似定位，不代表准确入口。价格、无障碍设施和大部分开放规则待核验。
- 不含实时余票、实时路况、实时租金、个人政务账户或自动资格审批。
- 初始活动为空，避免把过期或未经核实的活动当成当前活动。
- 答案质量和知识范围受已收录资料限制。匹配到资料不等于完成事实核验。生成式AI即使带引用，仍需人工抽查引用是否支持结论。

## 可选外部服务

复制 `.env.example` 为 `.env`，只在服务端填写配置。`AI_API_KEY`、微信AppSecret均不可放入小程序代码或聊天。

```dotenv
ADMIN_PASSWORD=替换为独立强密码
AI_BASE_URL=https://你的兼容服务/v1
AI_API_KEY=服务端密钥
AI_MODEL=实际模型名称
WECHAT_APP_ID=你的AppID
WECHAT_APP_SECRET=你的服务端AppSecret
```

AI使用兼容 `POST /chat/completions` 的服务。模型只获得检索命中的公开资料片段和最近对话，不获得数据库或管理员密码。服务失败、缺少引用或引用编号无效时退回资料摘要。外部服务账号、费用和数据处理条件需由使用者选择确认。

微信身份切换会改变用户身份，不自动合并游客资料；切换前可导出备份。当前游客会话有效期为30天，清除浏览器存储会失去该访问身份，请及时导出重要资料。

## 内容维护

1. 在“来源维护”登记来源，核对使用条件；当前采集只允许内置的官方域名范围。
2. “采集草稿”提取短页面元数据，不采集全文和图片。抓取规则不允许或无法确认时停止，改为人工整理。
3. 在资料审核中补充有依据的内容，填写核验日期和有效期；再设置 `published`。
4. 活动必须填写真实场地、起止日期、核验日期。过期活动自动退出公众列表。
5. 来源变化检查比较页面哈希，可能受到导航或动态页面影响；发现变化会形成待审任务，不代表内容事实已经变化。
6. 需要后台定时监测时设置 `ENABLE_SOURCE_MONITOR=true`，服务运行时每6小时检查到期来源。默认关闭，需先核对站点访问条件。部署需确保进程持续运行。

内容导入按来源、资料、地点、活动顺序进行。完整导出文件可在网页导入页选择对应类型分别导入。后台不是多人分工审批系统：当前为单管理员角色，审核状态由管理员维护。

## 目录

- `miniprogram/`：10个微信原生页面与共用请求模块。
- `src/`：响应式React网页、地图与管理后台。
- `server/`：接口、SQLite存储、资料检索、候选行程与初始资料。
- `tests/`：核心及真实HTTP接口测试。
- `docs/`：功能验收矩阵、接口说明、100题人工验收题库。
- `output/playwright/`：浏览器验证截图（本地生成，不含在源码包中）。

尚需的上线工作：微信工具/真机验证、账号与域名、部署与备份、内容扩充及逐项核验、按最终部署方案落实相应上线要求。当前不宣称正式可采购交付或全北京信息已收齐。

可选服务配置：复制 `.env.example` 为本项目的 `.env`，只在本机填写密钥；使用 `node --env-file=.env server/index.mjs` 启动以加载配置。普通 `npm start` 使用当前进程环境，不会自动读取 `.env`。Docker 内部端口为 8787，对外运行时需配置管理员密码。

视觉采用“稚拙城市手册”：奶油纸底、蓝墨、砖红印章、彩色便签和实景照片卡。网页样式见 `src/naive.css`，微信样式见 `miniprogram/naive.wxss`；均为本项目独立文件，不从其他城市加载。
