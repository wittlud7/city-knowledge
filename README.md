# 城知 · 把一座城，慢慢读懂

城市公开资料知识库与微信小程序。用有出处的资料连接住房、就业、教育、医疗、交通、公共文化与日常生活。

**中国大陆31个城市分别放在独立文件夹**，每城包含网页、原生微信小程序、服务端、公开资料、真实照片和独立数据库配置；不是仅切换城市名称的同一份资料。

![天津桌面端 · 手绘城市生活观察簿](docs/images/tianjin-desktop.png)

## 当前能做什么

- 浏览城市资料，按生活领域检索，查看日期、适用范围和原文出处。
- 使用检索摘要问答、追问、引用和回答反馈；预留兼容模型服务的接入配置。
- 收藏内容，保存生活清单，按已整理地点生成候选游览行程。
- 查看城市地图、真实照片和素材许可。
- 管理后台支持资料编辑、审核发布、版本记录、来源更新检查和纠错反馈。
- 本地总目录支持搜索31城、查看资料覆盖，并单独启动所选城市。

## 快速开始

推荐 Node.js 24。所有命令在仓库根目录运行。首次仅准备天津：

```sh
node city-program/setup.mjs --city tianjin
node city-program/server.mjs
```

打开 <http://127.0.0.1:8790/>，选择天津并点击“启动并打开”。也可在 `tianjin-city-guide` 中分别执行 `npm ci`、`npm run build`、`npm start`，打开 <http://127.0.0.1:8801/>。

准备全部城市：`node city-program/setup.mjs`。Windows 可使用 `city-program/Setup-Cities.cmd` 和 `city-program/Start-Cities.cmd`。

微信开发者工具导入对应城市文件夹中的 `project.config.json`。当前没有正式AppID，发布需要配置自有AppID、HTTPS后端和合法域名；浏览器与结构检查不能替代微信编译、真机验证和审核。

管理员首次启动密码保存在所选城市的 `data/admin-password.txt`，不在仓库中。可选模型配置参考各城 `.env.example`；复制为 `.env` 后，使用 `node --env-file=.env server/index.mjs` 启动以加载。不要将密钥放入前端或提交到仓库。

## 项目结构

```text
city-program/             城市总目录、覆盖清单、批量安装与构建工具
beijing-city-guide/       北京独立项目
tianjin-city-guide/       天津独立项目
shanghai-city-guide/      上海独立项目
…                        其余28城各有独立文件夹
  src/                   React网页和稚拙手册主题
  miniprogram/            原生微信小程序
  server/                API、资料检索和SQLite持久化
  content/               本城资料、照片出处与覆盖情况
  public/media/          真实城市照片
```

完整名单见 [31城项目与资料覆盖清单](city-program/城市项目与覆盖清单.md)。目录只在本机启动服务，上传源码不等于已部署公网服务。

## 资料范围与验证

2026-10-31整理的资料快照包括50篇本地正文、6篇全国通用资料（去重）、35张真实照片、97个地点。其中70条是带许可的公共地图参考记录，14城的公报补入49项保留年份与口径的背景事实。

**仍是可运行首版，资料并不完整。** 北京有15篇本地正文，其他城市各有1至2篇本地正文；全国资料在每城保存独立副本，不能重复计为独立研究。本市年度入学、租赁、医疗与交通等细则尚需逐城补齐。未成功读取的来源、未核验的领域、未定位的地点均保留边界说明。照片是历史影像，不表示实时状态；地图参考点不等于已核验的开放安排或入口。

2026-11-02升级为手绘城市手册：纸纤维、原创生活小画、手写旁注、胶带实景照片、章节编号与档案夹专题。网页标题字体为独立保存的OFL站酷快乐体子集，正文和引用保持平直并使用系统字体；微信标题使用系统字体。改版说明与字体许可见 [主题文档](city-program/稚拙风改版说明.md)。

验证记录见 `city-program/build-results.json`、`http-results.json` 和 `integrity-results.json`。在城市目录运行 `npm run build`、`npm test`、`npm run check:mini`；批量准备与校验工具见总目录README。默认使用检索摘要问答，尚无真实模型调用验证和微信真机发布结果。

## 图片、地图与公开资料

每城 `content/photos.json` 保留照片作者、日期、原始说明页及许可链接。地图数据来自 OpenStreetMap，保留 ODbL 署名与来源；详见 [公共地图数据说明](city-program/公共地图数据说明.md)。公开资料的来源、适用范围和原文链接在对应城市内容中记录。第三方素材和资料各按其原始许可使用，仓库没有用统一许可覆盖它们。

本项目为独立开发，暂无政府背书、签约客户或已验证试点效果。对外沟通可参考 [宣传与试点方案](city-program/宣传与试点方案.md)，其中目标与建议不代表已取得的成效。
